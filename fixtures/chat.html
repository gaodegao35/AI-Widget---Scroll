I'm building a CSV parser in Python. It needs to handle quoted fields that contain commas. Can you write a first version without using the csv module?

Here's a first version that walks the line character by character and tracks whether we're inside quotes:

python
def parse_line(line):
    fields, cur, in_quotes = [], [], False
    for ch in line:
        if ch == '"':
            in_quotes = not in_quotes
        elif ch == ',' and not in_quotes:
            fields.append(''.join(cur)); cur = []
        else:
            cur.append(ch)
    fields.append(''.join(cur))
    return fields

def parse_csv(text):
    return [parse_line(l) for l in text.splitlines() if l]

This handles a,"b,c",d → ['a', 'b,c', 'd']. It does not yet handle escaped quotes ("") or newlines inside quoted fields.

It breaks when a quoted field contains a newline. The row gets split in two.

Right — splitlines() runs before we know we're inside quotes. Version 2 parses the whole text as one stream and only ends a row on a newline that is outside quotes. It also handles the "" escape:

python
def parse_csv(text):
    rows, fields, cur, in_quotes = [], [], [], False
    i = 0
    while i < len(text):
        ch = text[i]
        if in_quotes:
            if ch == '"' and text[i+1:i+2] == '"':
                cur.append('"'); i += 1
            elif ch == '"':
                in_quotes = False
            else:
                cur.append(ch)
        else:
            if ch == '"':
                in_quotes = True
            elif ch == ',':
                fields.append(''.join(cur)); cur = []
            elif ch == '\n':
                fields.append(''.join(cur)); rows.append(fields)
                fields, cur = [], []
            else:
                cur.append(ch)
        i += 1
    if cur or fields:
        fields.append(''.join(cur)); rows.append(fields)
    return rows

The state is now explicit: we're either in quotes or not, and every character is handled in exactly one branch.

def coerce(s):
    if s in ('true', 'false'):
        return s == 'true'
    try:
        return int(s)
    except ValueError:
        pass
    try:
        return float(s)
    except ValueError:
        return s

What's the deal with the BOM issue from the table?

Files exported from Excel as "CSV UTF-8" start with the bytes EF BB BF, the UTF-8 byte-order mark. When you read the file as UTF-8, that becomes the invisible character ﻿ at the start of the first field, so "id" becomes "﻿id" and header lookups fail.

Two fixes: open the file with encoding="utf-8-sig", which strips it, or strip ﻿ from the start of the text yourself before parsing. The second is safer if you don't control how the file was opened.

This is the same scanner as the typed version in [turn 14], with one line added at the top and the quoted-field tracking so quoted numbers stay strings:

python
BOM = '﻿'

def parse_csv(text, typed=True):
    if text.startswith(BOM):
        text = text[1:]
    rows, fields, cur, in_quotes, quoted = [], [], [], False, []
    was_quoted = False
    i = 0
    while i < len(text):
        ch = text[i]
        if in_quotes:
            if ch == '"' and text[i+1:i+2] == '"':
                cur.append('"'); i += 1
            elif ch == '"':
                in_quotes = False
            else:
                cur.append(ch)
        else:
            if ch == '"':
                in_quotes = True; was_quoted = True
            elif ch == ',':
                fields.append(''.join(cur)); quoted.append(was_quoted)
                cur, was_quoted = [], False
            elif ch == '\n':
                fields.append(''.join(cur)); quoted.append(was_quoted)
                rows.append([f if q or not typed else coerce(f) for f, q in zip(fields, quoted)])
                fields, quoted, cur, was_quoted = [], [], [], False
            else:
                cur.append(ch)
        i += 1
    if cur or fields:
        fields.append(''.join(cur)); quoted.append(was_quoted)
        rows.append([f if q or not typed else coerce(f) for f, q in zip(fields, quoted)])
    return rows

quickcsv

A tiny dependency-free CSV parser for when you can't use the standard library (sandboxed environments, teaching, or embedding in a single file).

Features. Quoted fields with commas, escaped quotes (""), embedded newlines, UTF-8 BOM stripping, optional type inference (int / float / bool), quoted values are never coerced.

Usage. from quickcsv import parse_csv; rows = parse_csv(open('f.csv', encoding='utf-8').read())

Performance. About 20× slower than the C csv module — see the benchmark table in [turn 16]. Fine for files under ~10 MB.

Tests. pytest, six cases covering every row of the edge-case table.

One more: how exactly does v4 handle a quote character inside a quoted field?

Inside quotes, the scanner in [ref: "text[i+1:i+2]"] looks one character ahead. If the next character is also a quote, it emits a single literal quote and skips both; otherwise the quote closes the field. That's this branch:

    cur.append('"'); i += 1
elif ch == '"':
    in_quotes = False
